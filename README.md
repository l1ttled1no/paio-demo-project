# PAIO Demo Project

Author: l1ttled1no

This is a demo project to configure an AUTOSAR project (Adaptive/Classic) using PAIO. The project is structured to demonstrate the capabilities of PAIO in managing and configuring AUTOSAR components effectively.

## Usage 

To use this demo, download the PAIO tool first at here: [PAIO Tool](https://autosar.io/en/products/paio)

Note: The Code Generation feature is not available now. Please wait for the next 2 weeks release. Until then, please try to make a new project, or based on this project, add your new executable, communications, services,... based on the demo project. 

After the Code Generation feature is available, you can generate the code for your project and run it on your target platform. The code will be built based on PARA Container (Link: [PAIO PARA Container](https://autosar.io/en/products/para)). You SHOULD run the PARA Container on Linux platform instead of Windows (but it still works on Windows as well).

Good luck.
